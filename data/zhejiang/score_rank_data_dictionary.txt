────────────────────────────────────────────────────────────
字段名（英文）: exam_year
字段名（中文）: 高考年份
数据类型      : SMALLINT（整数）
含义说明      : 高考所属年份
取值范围      : 2023 / 2024 / 2025
是否可空      : NOT NULL
示例数据      : 2024
备注          : 主键联合字段之一，建索引时放第一位

────────────────────────────────────────────────────────────
字段名（英文）: score
字段名（中文）: 高考总分
数据类型      : SMALLINT（整数）
含义说明      : 考生的高考文化课总分（满分750分）
取值范围      : 268 ~ 699（连续无缺口）
是否可空      : NOT NULL
示例数据      : 483
备注          : 浙江省不分文理科，所有考生统一计分，分数从高到低排列

────────────────────────────────────────────────────────────
字段名（英文）: rank
字段名（中文）: 全省累计位次
数据类型      : INTEGER（整数）
含义说明      : 该分数在全省考生中的累计排名（同分按省考试院规则排定）
取值范围      : 1 ~ 290790（取决于当年总考生数）
是否可空      : NOT NULL
示例数据      : 187304
备注          : 核心查询字段。位次严格单调递增（分数越低，位次越大）

────────────────────────────────────────────────────────────
字段名（英文）: section_num
字段名（中文）: 本段人数
数据类型      : INTEGER（整数）
含义说明      : 取得该分数的考生人数
取值范围      : 1 ~ 约1200
是否可空      : NOT NULL
示例数据      : 1047
备注          : 所有分数 section_num 累加 = total_student（已校验通过）

────────────────────────────────────────────────────────────
字段名（英文）: category
字段名（中文）: 考生类别
数据类型      : VARCHAR(10)
含义说明      : 招生类别的分类
取值范围      : 普通类 / 艺术类 / 体育类
是否可空      : NOT NULL
示例数据      : 普通类
备注          : 当前数据仅包含「普通类」。艺术类、体育类暂无原始数据

────────────────────────────────────────────────────────────
字段名（英文）: subject_type
字段名（中文）: 选考科目类型
数据类型      : VARCHAR(10)
含义说明      : 考生所选高考科目的类别划分
取值范围      : 综合类 / 物理类 / 历史类
是否可空      : NOT NULL
示例数据      : 综合类
备注          : 浙江省「3+3」不分文理，全省统一为「综合类」。物理类/历史类仅用于其他省份

────────────────────────────────────────────────────────────
字段名（英文）: batch
字段名（中文）: 录取批次
数据类型      : VARCHAR(10)
含义说明      : 该分数段所属的录取批次
取值范围      : 一段 / 二段
是否可空      : 可空
示例数据      : 一段
备注          : 浙江一段线约前60%考生，二段线为后续考生。用于志愿填报批次匹配

────────────────────────────────────────────────────────────
字段名（英文）: rank_percent
字段名（中文）: 位次占比
数据类型      : NUMERIC(8,4)（小数）
含义说明      : rank / total_student，表示该位次在全体考生中的百分比位置
取值范围      : 0.0000 ~ 1.0000（保留4位小数）
是否可空      : NOT NULL
示例数据      : 0.6664
备注          : 衍生字段。用于志愿系统快速定位考生所处竞争区间（如 top 10%/20%）

────────────────────────────────────────────────────────────
字段名（英文）: total_student
字段名（中文）: 该类别总考生数
数据类型      : INTEGER（整数）
含义说明      : 该年份 + 该类别的全省报考总人数
取值范围      : 277524 / 281057 / 290790
是否可空      : NOT NULL
示例数据      : 281057
备注          : 同一（年份+类别）下所有行该值相同。用于计算 rank_percent
