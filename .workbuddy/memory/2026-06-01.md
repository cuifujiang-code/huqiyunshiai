   - 修复：在 `apiRouter.js` 中添加 decompose-submit/status/tasks/process 四个路由的分发
   - 同时在 `vercel.json` 中注册这些端点的 functions 配置

## 公式/图片自动渲染完整实现（第六轮）

### 用户核心需求
「想要在预览题目的时候公式和图片都已经是渲染出来的，不需要手动添加，这样才是真正的成功拆题」

### 实现方案（已上线 ✅）
**核心思路**：利用 DOCX 内部已有 WMF 公式渲染图，无需 AI 推断 LaTeX。

**数据流**：
```
本地 DOCX → docx_image_extractor.py 提取 WMF→PNG(base64)
→ 上传时附带 imagesJson（含 formulas + images base64）
→ API 存入 task.meta JSONB
→ Worker 拆题 → normalizeQuestion() 替换占位符
→ content 字段含 <img src="data:image/png;base64,..."> 标签
→ 前端 MathRenderer.tsx 渲染 <img> + KaTeX 公式
```

### 关键文件改动
1. **`_scripts/docx_image_extractor.py`**（新建）
   - 从 DOCX zip 中读取 word/document.xml + word/_rels/document.xml.rels
   - 建立 OLE 公式对象 → WMF 渲染图 → PNG base64 映射
   - 实测：252 个公式，252/252 WMF→PNG 成功，~4ms/公式

2. **`teacher-api/server/batch/questionNormalizer.js`**
   - 新增 `replaceFormulaPlaceholders()`：替换 `【公式】` → `<img>` 标签
   - 新增 `replaceImagePlaceholders()`：替换 `[图片占位符]` → `<img>` 标签
   - 修复 `cleanText()`：`【】` 全角符号不再被转为 `[]`（之前导致占位符匹配失败）
   - 边界保护：单题最多 50 个公式、20 张图片，base64 超 15KB 截断

3. **`teacher-api/api/batch/upload.js`**
   - 接收 `imagesJson` 参数，存入 `task.meta` JSONB 字段
   - Body size limit 50MB（vercel.json 配置）

4. **`teacher-api/server/batch/batchWorker.js`**
   - 从 `task.meta` 读取 `formulaImages` 和 `images`
   - 传给 `forceDecomposeAndInsert()`

5. **`teacher-api/server/batch/robustDecomposer.js`**
   - `forceDecomposeAndInsert()` 接受 `options.formulaImages` 和 `options.images`
   - 传入 `taskMeta` 供 `normalizeQuestionsBatch()` 使用

6. **`src/components/common/MathRenderer.tsx`**
   - 新增 `renderWithHtmlTags()`：保留 `<img>`、`<br>`、`<hr>` 标签，其余文本转义
   - 新增 HTML 渲染缓存（Map，最多 500 条，防止重复解析）
   - 修复正则：`/<img\s[^>]*\/?>/` 精确匹配自闭合 img 标签
