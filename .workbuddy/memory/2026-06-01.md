## 批量拆题修复（第三轮）

### 发现的根本问题
用户反馈批量拆题仍然失败 + `batch_decompose_tasks` 返回 0 结果。经排查发现**两个独立问题**：

1. **`safeJsonParse` bug（之前已修复）**：`seen.add(candidate)` 在外层循环过早执行，导致内层 `seen.has(attempt)` 跳过所有合法 JSON。修复：移除外层 `seen.add(candidate)`。

2. **decompose-* API 端点 404（本次修复）**：
   - `api.huqiyunshiai.online/api/decompose-tasks` 返回 404 "未知路由"
   - 根因：`teacher-api/server/apiRouter.js` 的 `dispatchApiRequest()` 只处理 `/api/batch/*` 和 `/api/teacher/*`，未注册 `decompose-*` 路由
   - 修复：在 `apiRouter.js` 中添加 decompose-submit/status/tasks/process 四个路由的分发
   - 同时在 `vercel.json` 中注册这些端点的 functions 配置
