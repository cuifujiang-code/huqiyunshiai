## 步骤二：推送代码到 GitHub

在 **Cursor** 中打开终端：**菜单 Terminal → New Terminal**

然后 **按顺序** 执行以下命令（每条单独复制粘贴，回车执行）：

### 2.1 进入项目目录

```powershell
cd "e:\华祺云师AI"
```

> **作用**：切换到项目根目录，后续所有 Git 命令都在这里执行。

### 2.2 确认 Git 状态

```powershell
git status
```

> **作用**：查看当前仓库状态。应显示 `On branch main`，并列出已修改或未跟踪的文件。

### 2.3 添加所有文件到暂存区

```powershell
git add .
```

> **作用**：把项目所有文件加入「待提交」列表。  
> **注意**：`.env` 文件已被 `.gitignore` 排除，**不会**上传你的密钥。

### 2.4 提交到本地仓库

```powershell
git commit -m "首次部署：华祺云师AI v1.0"
```

> **作用**：在本地保存一次版本快照。  
> 若提示 `nothing to commit`，说明已经提交过，可跳过此步继续推送。

### 2.5 关联 GitHub 远程仓库

**把下面命令中的地址换成你在步骤一复制的地址：**

```powershell
git remote add origin https://github.com/cuifujiang-code/huqiyunshiai.git
```

> **作用**：告诉 Git，代码要推送到哪个 GitHub 仓库。

**若提示 `error: remote origin already exists`（远程已存在）**，改用：

```powershell
git remote set-url origin https://github.com/cuifujiang-code/huqiyunshiai.git
```

> **作用**：更新已存在的远程地址。

### 2.6 推送到 GitHub

```powershell
git push -u origin main
```

> **作用**：把本地代码上传到 GitHub。  
> 首次 push 可能弹出浏览器，要求登录 GitHub 并授权，按提示操作即可。

### 2.7 推送成功的标志

- 终端最后一行类似：`Branch 'main' set up to track remote branch 'main' from 'origin'.`
- 打开 https://github.com/cuifujiang-code/huqiyunshiai ，能看到 `src`、`vercel.json`、`package.json` 等文件夹

### 2.8 推送失败？常见原因与解决办法

| 错误提示 | 原因 | 解决办法 |
|----------|------|----------|
| `git 不是内部或外部命令` | Git 未安装或未加入 PATH | 安装 Git 后**完全重启 Cursor** |
| `Authentication failed` | GitHub 登录失败 | 使用 Personal Access Token 作为密码，或用 GitHub Desktop 登录 |
| `remote origin already exists` | 已添加过远程 | 用 `git remote set-url origin ...` 更新地址 |
| `failed to push some refs` | 远程仓库有 README 等文件 | 删除 GitHub 仓库重建（不勾选 README），或执行 `git pull origin main --rebase` 后再 push |
| `Repository not found` | 仓库地址错误或无权访问 | 检查用户名、仓库名是否为 `huqiyunshiai` |

## 步骤三：在 Vercel 导入项目

### 3.1 登录 Vercel

1. 浏览器打开：**https://vercel.com**
2. 点击 **Sign Up** 或 **Log In**
3. 选择 **Continue with GitHub**
4. 按提示授权 Vercel 访问你的 GitHub 账号

### 3.2 进入导入页面

1. 登录后打开：**https://vercel.com/dashboard**
2. 点击右上角 **Add New…** 按钮
3. 在下拉菜单中点击 **Project**

### 3.3 选择仓库

1. 在 **Import Git Repository** 列表中找到 **`huqiyunshiai`**
2. 若看不到该仓库：
   - 点击 **Adjust GitHub App Permissions**（调整 GitHub 应用权限）
   - 勾选 **`huqiyunshiai`** 仓库
   - 保存后回到 Vercel 刷新页面
3. 点击仓库右侧的 **Import** 按钮

### 3.4 确认构建配置（全部保持默认）

Vercel 会自动识别为 **Vite** 项目，确认以下项（一般无需修改）：

| 配置项 | 默认值 |
|--------|--------|
| Framework Preset | Vite |
| Root Directory | `./` |
| Build Command | `npm run build` |
| Output Directory | `dist` |
| Install Command | `npm install` |

### 3.5 开始部署

**不要修改任何配置**，直接点击页面底部的 **Deploy** 按钮。

### 3.6 等待多久能看到网址

- 页面会显示 **Building…** 和滚动日志
- 通常 **1～3 分钟** 完成
- 出现 **Congratulations!** 和网站预览图即表示部署成功
- 页面顶部会显示你的网址，格式类似：

```
https://huqiyunshiai.vercel.app
```

或：

```
https://huqiyunshiai-你的用户名.vercel.app
```

点击 **Visit** 即可打开网站。

## 步骤四：配置环境变量

> **演示版可以不配置任何环境变量**，网站也能完整运行（本地模拟登录 + 模拟 AI 数据）。  
> 若你已有 Supabase 等项目，可按以下步骤配置。

### 4.1 打开环境变量设置

1. 在 Vercel Dashboard 点击项目 **`huqiyunshiai`**
2. 点击顶部菜单 **Settings**
3. 在左侧菜单点击 **Environment Variables**

完整路径：**项目 → Settings → Environment Variables**

### 4.2 需要添加的环境变量

在 Vercel 中逐个添加以下变量（**Value 留空，由你自己填写**）：

| 变量名（Key） | 是否必填 | 说明 |
|---------------|----------|------|
| `VITE_SUPABASE_URL` | 可选 | Supabase 项目 URL |
| `VITE_SUPABASE_ANON_KEY` | 可选 | Supabase 匿名公钥 |
| `VITE_QINIUAI_API_KEY` | 可选 | 七牛云 AI API Key |
| `VITE_QINIUAI_API_URL` | 可选 | 如 `https://api.qnaigc.com/v1` |
| `VITE_QINIUAI_MODEL` | 可选 | 如 `deepseek-v3` |

添加每一条的步骤：

1. 在 **Key** 输入框填入变量名（如 `VITE_SUPABASE_URL`）
2. 在 **Value** 输入框粘贴你的真实值
3. 在 **Environment** 勾选：**Production**、**Preview**、**Development**
4. 点击 **Save**

> 完整变量清单见项目根目录文件 **`.env.example`**

### 4.3 让配置生效（必须重新部署）

环境变量修改后 **不会自动生效**，需要重新部署：

1. 点击顶部菜单 **Deployments**
2. 找到最新一条部署记录
3. 点击右侧 **⋯**（三个点）
4. 选择 **Redeploy**
5. 在弹窗中再次点击 **Redeploy**
6. 等待 **1～2 分钟** 完成
