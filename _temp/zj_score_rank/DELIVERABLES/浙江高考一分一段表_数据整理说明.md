## 三、数据清洗规则

| 规则编号 | 规则名称 | 说明 |
|---------|---------|------|
| R01 | 特殊符号清除 | 分数中的「↑」「≥」「*」「#」等符号全部去除，保留纯数字 |
| R02 | 空值处理 | 本段人数（section_num）缺失时保留为空，不补零，不影响位次字段 |
| R03 | 去重 | 同年份同分数只保留一行，取累计人数（位次）最大的记录 |
| R04 | 排序 | 每个分类按分数从高到低排列 |
| R05 | 异常标注 | 分数超出0-750、位次≤0、人数<0 的数据在 remark 字段标注，不删除 |
| R06 | 衍生字段 | total_student=该分类最大位次值；rank_percent=rank/total_student（4位小数） |
| R07 | 编码 | CSV 使用 UTF-8 BOM 编码，确保 Excel 直接打开不乱码 |

## 六、字段说明

| 字段名 | 中文名 | 类型 | 说明 |
|--------|--------|------|------|
| `exam_year` | 高考年份 | 整数 | 2023/2024/2025 |
| `score` | 高考总分 | 整数 | 0-750，含「↑」的最高分行已清理 |
| `rank` | 全省累计位次 | 整数 | 全省总排名（累计人数），核心字段 |
| `section_num` | 本段人数 | 整数/空 | 该分数对应考生人数，最高分首行可能为空 |
| `category` | 考生类别 | 枚举 | 普通类（本数据均为普通类） |
| `subject_type` | 选考科目类型 | 枚举 | 综合类（浙江不分物理/历史大类） |
| `batch` | 批次 | 枚举 | 一段（一分一段表均为一段） |
| `remark` | 备注 | 字符串 | 无/异常标注 |
| `rank_percent` | 位次占比 | 小数 | rank/total_student，保留4位小数，用于换算百分比位次 |
| `total_student` | 该类别总考生数 | 整数 | 取该分类最大累计位次值 |
